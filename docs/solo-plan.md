# 1인 개발 일정 (11/9 ~ 12/6)

계획서(「위치·QR 기반 출결 관리 서비스 — 계획서 및 개요서」)의 기본 기능 B-01~B-12를 혼자 4주 안에 끝내기 위한 일정입니다.
3인 일정과 달리 **백엔드 API → 그 API를 쓰는 화면**을 기능 하나씩 세로로 완성합니다. 그래야 매주 끝에 "돌아가는 것"이 남습니다.

## 1인 개발을 위한 범위 조정

- 심화 기능(D-xx)은 12/6 이전에는 손대지 않는다.
- 프론트는 JavaScript(React + Vite)로, TypeScript는 쓰지 않는다.
- 로컬 개발은 H2(MySQL 호환 모드)로, MySQL은 배포할 때만 쓴다.
- 휴대폰 테스트는 배포 전까지 ngrok HTTPS 터널로 한다(카메라·위치는 HTTPS 필수).
